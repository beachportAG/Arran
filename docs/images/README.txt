Put photos here.

  images/hero.jpg                       wide shot for the homepage hero (1920x1080)
  images/arran.jpg                      photo of Arran (600x740, portrait)
  images/projects/<name>-before.jpg     before photo for a project
  images/projects/<name>-after.jpg      after photo for the same project
  images/projects/<name>.jpg            single finished photo (no before shot)

Before/after pairs MUST be the same aspect ratio and framed from roughly the
same spot, or the slider looks broken.

Optimize before committing. Target 1600px wide and under 300KB each.
Free tool: https://squoosh.app  (set Resize width 1600, format WebP or JPEG q75)
